# LNAXY REALISM 0.3.0 — shader settings

The Iris/OptiFine **Shader Pack Settings** menu now includes LOW, MEDIUM, HIGH, and ULTRA profile presets plus adjustable color/post-processing and water controls.

Available controls: exposure, contrast, saturation, vignette, a low-cost 4-tap bloom approximation, water tint, and water opacity.

These controls are intentionally limited to effects currently implemented in this starter shader. This build still does not contain shadow mapping, volumetric fog, reflective/refractive water, caustics, or labPBR material rendering. The LOW–ULTRA profiles tune the current effects; they are not yet GPU-quality tiers with different shadow resolutions.
